✅ Easiest method — no code, no account linking. Just drag and drop.

  1. Create a free GitHub account

    Go to github.com → Sign up (free).

  2. Create a new repository

    Click + → New repository. Name it (e.g. birthday-fruit). Set it Public. Click Create repository.

  3. Upload the files

    Click Add file → Upload files → drag all 4 files in → click Commit changes.

  4. Enable GitHub Pages

    Go to Settings → Pages → Source: Deploy from branch → Branch: main / / (root) → Save.

  5. Wait 1–2 min, then share! 🎉
